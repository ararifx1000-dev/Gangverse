GANGVERSE upload files
======================
Upload these files and folders to the ROOT of your GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- icons/ (folder containing icon-192.png and icon-512.png)

Do not upload this ZIP as a single file if you want GitHub Pages to display the site.
After uploading, enable GitHub Pages in repository Settings > Pages > Deploy from a branch > main > /(root) > Save.

This is a front-end demo only. Chats are local to the device; there is no real login,
shared database, live messaging, video/voice calls, or cloud uploads yet.
